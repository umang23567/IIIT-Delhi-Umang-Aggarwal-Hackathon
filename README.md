## 1. Project Overview / Problem Statement & Approach

Financial text (news, social posts) moves faster than risk systems can read it, and most
sentiment tools score each headline in isolation. **ContagionLens** is an NLP risk engine that turns
news and tweets into structured signals (sentiment, event class, impact, entity, source credibility)
and then asks the question a risk desk cares about: *who else gets hurt?* Signals propagate over an
exposure graph (supply chain, peer banks, lending links), with bad news travelling further than good.

Four modules consume the engine: **A** a tactical, contagion-aware index rebalancer; **B** an
event-triggered stress tester for a synthetic wholesale-banking book; **C** a signal validator that
benchmarks the engine against a naive baseline; **D** an explainable daily risk brief. A rumour filter
down-weights uncorroborated social posts so a viral false claim cannot trigger a stress test.

## 2. Architecture & Tech Stack

Python 3.11+, pandas/numpy, Streamlit + Plotly (dashboard), FastAPI (signal API).
NLP backend: transparent finance lexicon + rules (offline, explainable); optional FinBERT via `USE_FINBERT=1`.

| Path | Role |
|---|---|
| `src/engine.py`, `src/nlp.py` | ingestion, dedupe, sentiment/event/impact, rumour filter |
| `src/graph.py` | contagion graph and propagation |
| `src/modules/` | A rebalancer, B stress, C validator, D brief |
| `src/pipeline.py` | end-to-end run, writes `output/` |
| `src/api.py`, `src/dashboard.py` | REST API and dashboard |

## 3. Dataset Used

- **Synthetic** (generated by `src/data_gen.py`, seed 7): ~240 news items, ~1,500 tweets (incl. retweets,
  chatter and unverified rumour bursts), 45 business days of prices for 15 S&P 100 names, and a 60-position
  wholesale book (loans, bonds, swaps, options, equities). All committed in `data/`.
- Contagion edges are hand-built, illustrative weights (`src/config.py`).
- **Assumptions / limitations:** prices contain a *planted* event-to-return effect, and the text is templated
  with the same vocabulary as the lexicon. Metrics on this data (IC, NLP accuracy) therefore verify the
  plumbing, not real-world performance. The pipeline accepts real data: drop CSVs with `text,timestamp[,followers]`
  into `data/news.csv` / `data/tweets.csv` and use `src/prices.py::fetch_yfinance` for real prices.

## 4. Quickstart & Installation

Runtime: Python 3.13 on Linux (tested); Python 3.11+ expected to work.

```bash
git clone <your-repo-url>
cd iiitd-umang-hackathon
pip install -r requirements.txt
python main.py all --regen          # engine + modules A-D, writes ./output
streamlit run src/dashboard.py      # dashboard
uvicorn src.api:app --reload        # optional REST API, docs at /docs
python main.py analyze "Boeing misses bond payment, default fears grow"
```
